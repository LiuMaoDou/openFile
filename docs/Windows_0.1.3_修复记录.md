# FileM 0.1.3 / openFile 开发与验证记录

日期：2026-09-13。源码仓库：https://github.com/LiuMaoDou/openFile 。桌面名称和应用标识保持 FileM / `local.filem.desktop`，升级保留已添加的文件夹、索引与删除记录。新增移动记录使用索引版本 3。

## 功能

1. **扫描状态可见**：列表上方显示扫描中、暂停、完成、完成时间或需要核对的问题。左侧每个监控文件夹显示状态和文件数量。
2. **类型跟随文件夹**：文件类型、后缀和数量只统计所选文件夹，零数量分类不显示；切换文件夹清除旧的分类与后缀。统计请求带文件夹标识，过时响应不能覆盖新选择。
3. **多选移动**：选择文件、目标文件夹、查看冲突清单后确认；同名目标和重复文件名默认跳过。每份计划有效 10 分钟且只执行一次，执行前复核源文件和目标目录身份，提供逐项结果、停止后续、后台处理和移动历史。暂停扫描并及时更新索引，移至已监控目录保留文件 ID，移至外部目录从视图移除。Windows 使用原生跨盘移动且不设置覆盖标志；macOS 跨卷复制分支验证内容后移除源文件。
4. **Everything SDK 可选加速**：静态编译官方 SDK，无单独 DLL。需要 Windows 上运行 Everything 1.4；SDK 本身不建立 Everything 的索引。初次扫描最多预填 2,000 个候选结果，之后本地扫描完整核对；搜索最多处理 50,000 个 SDK 候选路径，再按真实元数据、授权文件夹及排除规则过滤。查询进程有 6 秒超时，查询冲突、未连接、超时或过多结果自动使用 SQLite。搜索按文字字面量处理，不开放高级语法与正文搜索。

- macOS 工作区及 Windows 核心 / 全部测试目标 Clippy 严格检查通过；TypeScript、Vite、Rust 格式检查通过。

## 来源与构建

- [Everything 官方 SDK](https://www.voidtools.com/support/everything/sdk/)，MIT 许可及下载校验值随源码和发行包提供。
- [Windows MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)：跨卷、禁止覆盖与刷盘行为。
- Windows 构建：`npm run windows:build`；完整检查命令见 README。运行不要求用户安装 Node.js 或 Rust。
