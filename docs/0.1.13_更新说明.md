# FileM 0.1.13：关键词搜索与大文档索引

本版本仅发布 Windows x64 安装版与便携版，不发布 macOS 安装包。

## 搜索改进

- 文件名、路径和正文均新增“关键词匹配”，中文自动分词，多词要求全部匹配。例如“2026 合同 最终版”和“合同 付款”。
- 默认仍为“精确匹配”，保留连续原文、空格与特殊符号的搜索行为。
- 文件名相关度优先完整名称和连续片段；正文按 BM25 相关度排序。可切换文件名、大小等排序。
- 保留 `AB-123`、`C++` 等技术词；词典边界不同或词索引未就绪时，正文逐词字面匹配兜底，避免漏掉“劳动合同”中的“合同”。单次最多 32 个关键词。
- 旧正文词索引后台自动补建，无需重新解析源文件。暂停的文件夹继续后处理；禁用、重建、文件变更和移除时同步清理。
- 关键词模式使用本地索引；精确文件名搜索仍可使用 Everything 加速。“文件名 + 内容”要求名称/路径或正文一侧满足全部词。

## 大文档索引

- 提取文字上限由 2 MiB 提升至 32 MiB UTF-8，原始文件上限仍为 64 MiB。
- 旧版截断文档自动补建；失败时保留原有部分内容并显示原因，可通过重建重试。
- 使用分批二进制传输与待提交正文/分词缓冲预算，及时提交已完成文档，减少大批量正文同时驻留。
- 预览只返回命中附近最多 16,384 个字符，支持大文档末尾命中；窄窗口搜索栏自动换行。

## 升级与边界

先退出旧版，再安装或完整解压新版。原有文件夹、设置和索引位置保留。首次启动会补建内容词索引，可能暂时增加 CPU 与磁盘使用；可在“内容索引”中暂停。

词索引和更长正文会增加索引空间，当前没有总配额或低磁盘自动暂停。字面匹配兜底在大量文档下仍可能较慢，不提供语义搜索、同义词搜索或 OCR。

Windows 安装包未做代码签名。自动化测试和包结构验证不能替代 Windows 桌面安装、原生弹窗及长期运行的实机验收。
