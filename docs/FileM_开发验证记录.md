## 十万文件基准

命令：`CARGO_BUILD_JOBS=2 FILEM_BENCH_COUNT=100000 npm run bench:index`。源码：`crates/filem-core/examples/benchmark.rs`。release 构建；100 个目录、100,000 个临时元数据样本，5 次完整扫描，100 次后缀与排序查询。该次基准发生在加入删除模块之前；扫描实现与交付版一致。

| 指标 | 实测 |
| --- | --- |
| 5 次扫描，含合并等待 | 21.653 / 31.155 / 38.941 / 35.327 / 34.799 秒 |
| 扫描中位数 / 最慢 | 34.799 / 38.941 秒 |
| 查询 P50 | 40.686 ms |
| 查询 P95 | 52.108 ms |
| 查询最大值 | 70.668 ms |

测量点包含后端查询与排序，**不含 IPC、浏览器渲染或进程启动**。文件刚生成后重复扫描，未控制冷缓存；没有采集完整进程组峰值内存。该结果不是严格冷/热缓存对照，也不能用于宣称端到端 P95、百万文件成绩或 Windows 性能。源代码修复了扫描逐条重新解析 SQL 的开销，批写现使用预编译语句缓存。

## 尚待验证与实现边界

- Windows：x64 release 交叉编译、NSIS 安装包和免安装包已生成，核心 Windows Clippy 检查通过，详见 [Windows 构建记录](Windows_构建记录.md)。实机运行、`IFileOperation` 回收、不可回收卷/网络路径、文件锁与权限、长路径/UNC/junction/OneDrive、目录选择、安装与启动仍待验收。原生回收要求标志的依据见 [Microsoft SetOperationFlags 文档](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)。
- macOS：桌面壳产物的原生窗口交互、目录选择与系统打开/定位未通过本次浏览器控制进行实机 UI 验收。已验证的真实回收来自共用 Rust 核心。
- 文件操作仍使用路径型 OS 接口，前置身份/大小/mtime 检查缩小风险窗口，不能消除检查与调用之间所有外部并发替换。未提供永久删除、应用内自动恢复或跨平台恢复承诺。
- 事件合并后核对整个范围；尚无路径增量、离线自动重连、稳定查询快照、复制/移动/重命名、缩略图、重复检测和版本分组。
- 移除范围不清除历史删除记录。历史记录保留在本机数据库，界面显示最近 10 批；未提交预览超过 10 分钟后在下一次预览时清理。
