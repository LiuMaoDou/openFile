# FileM 0.1.16 · 文件列表列宽与列顺序（Windows）

本版本基于 0.1.15，保留已有的文件索引、查询、内容搜索、文件操作与安全校验功能。

## 新增功能

- 文件列表的 **文件名、所在目录、大小、修改时间、类型** 五列支持拖动列标题调整位置。选择框和「操作」列保持固定。
- 将鼠标移至列头右侧分隔线，拖动即可调整该列宽度；文件名和所在目录等长内容可按需要扩宽查看。
- 自动在本机保存列顺序和列宽，关闭、重新打开程序后继续使用上次布局。
- 提供键盘操作：在列头按 `Alt + ← / →` 移动列；聚焦列分隔线后按左右方向键微调宽度，按住 `Shift` 可加快调整。
- 文件排序、勾选、多选、虚拟滚动、分页与打开/定位文件的行为保持不变。

## Windows 发行包

- Windows x64 安装版：`FileM_0.1.16_x64-setup.exe`。
- Windows x64 便携版：`FileM-0.1.16-windows-x64-portable.zip`。
- `SHA256SUMS.txt`：安装版与便携版的 SHA-256 校验值。

便携版解压后运行 `FileM.exe`，依赖系统 WebView2。安装版由 Tauri 安装流程处理 WebView2。安装包尚无代码签名；Windows 实机交互与多磁盘场景仍需验证。

本次列布局新增单元测试，并加入 Windows/macOS 自动检查。CI 编译与测试通过不等于所有实际设备均已验收。
