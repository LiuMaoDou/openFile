# FileM 0.1.11：隐藏目录与界面精简

## 目录隐藏与恢复

- 点击文件，在详情弹窗中选择“隐藏所在目录”，可隐藏整个目录及其子目录中的文件。目录规则会保留，新文件也遵循规则。
- 在“已隐藏 → 管理目录规则 → 恢复显示”中恢复目录；单独隐藏的文件和其他目录规则继续生效。
- 隐藏只影响 FileM 视图，源文件保留原位。目录规则按路径保存，不自动跟随目录改名。

## 扫描与问题详情

- 扫描默认使用高性能配置，按本机 CPU 分配线程，移除性能档位选择，旧版保存的档位不再影响扫描。
- 无法完成扫描的文件或目录会列出完整路径、类型和原因，支持分页及复制本页路径。
- 未完成路径保留旧索引；核对成功后清除对应问题。旧版只有失败数量的记录，需要刷新后补充路径详情。

## 界面

- 搜索框、下拉框、常规按钮、内容索引及扫描状态折叠栏统一为 42px，文件表格每行也为 42px。
- 状态移到页面标题旁，文件夹数量与搜索结果文件数量合并在底部，去掉底部统计栏上方线条。
- 添加文件夹只保留左侧入口，移除“文件库、监控文件夹、文件类型、外观”等分区标题及多余说明文字。
- 移除移动记录、删除记录入口，本次操作弹窗仍提供执行结果。
- 文件详情的预览、复制路径、隐藏目录和删除按钮集中排列。
- 原有 11px 字体统一为 12px；字体顺序为 Ubuntu、微软雅黑、Yuanti SC 及其他兜底字体。

## 升级与运行

- 先退出旧版，再安装或替换应用。已有文件夹、文件隐藏记录与内容索引继续保留。
- 索引自动升级到版本 5，升级后请使用 FileM 0.1.11 或更新版本。
- Windows 安装版可在缺少 WebView2 时引导联网安装；便携版需要系统已有 WebView2。
- Intel Mac 包采用临时签名，未使用 Apple Developer ID 签名且未经公证。首次打开如被阻止，确认来源后到“系统设置 → 隐私与安全性 → 仍要打开”。Windows 包未做代码签名。
- Windows 安装、长路径、网络盘、云占位文件与长期扫描仍需真实桌面环境验收；当前发布校验结果以 GitHub Release 说明为准。
