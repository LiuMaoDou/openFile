# FileM 0.1.8：扫描读写并行与多目录调度

本版提供 Windows x64 安装版、免安装 ZIP，以及 Intel Mac DMG 和 ZIP。安装前先退出旧版 FileM，已有监控文件夹、隐藏记录与内容索引继续保留，无需清空数据库。

## 本次改进

- 扫描读取与数据库批量写入并行，减少重复 SQL 查询和未变化文件的元数据更新。大目录中的文件信息分批处理，降低峰值内存。
- 同时等待扫描的父子范围合并遍历，分别保留各自的排除规则、递归设置与进度。
- 多个目录共用读取线程池，同卷任务排队，不同卷可并行，减少资源争用。卷识别基于监控根目录；底层物理设备与嵌套挂载关系未完整建模。
- 取消或修改一个范围时，其他范围可以继续。移动、删除文件时排空扫描读写队列，恢复后重新核对被中断的批次，避免过期结果重新写回索引。

## 性能与验证

本地 Intel Mac 上，10 万个临时文件的重复扫描中位数：目录树从 6.63 秒降到 5.27 秒，同卷四个目录从 7.67 秒降到 3.94 秒，单个大目录从 6.42 秒降到 1.89 秒。三种场景的峰值内存中位数降至约 23–24 MiB。

每种实现、每种场景记录 6 次重复扫描；耗时存在明显波动，以上为本轮样本结果，不代表所有设备、Windows、网络盘或正文提取的提速比例。完整范围、原始数据与测试方法见 [扫描优化验证记录](扫描优化1和2_验证记录.md)。

本地 68 项核心/集成测试、内容提取与全文检索冒烟、前端构建、Rust 检查、严格 Clippy 与 Windows x64 交叉编译检查通过。Windows 安装、多磁盘、网络盘、云占位文件及全部原生桌面交互仍需目标环境验收。

## 安装说明

Windows 安装版在缺少 WebView2 时引导联网安装；免安装包完整解压后运行 `FileM.exe`。Mac 打开 DMG 后，将 `FileM.app` 拖入 Applications（应用程序）。

本版仍为开发验证版。Mac 包使用临时签名，没有 Apple Developer ID 签名且未经公证；首次打开如被阻止，确认来源后可到“系统设置 → 隐私与安全性 → 仍要打开”。Windows 包未做代码签名。
