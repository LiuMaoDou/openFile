# FileM 0.1.12：索引存储管理

本版本仅发布 Windows x64 安装版与便携版。

## 新增功能

- 左下角新增“索引存储”，显示当前索引完整路径、数据库、写入日志（WAL）和索引文件合计大小。
- “定位索引文件”在系统文件管理器中选中索引，便于检查占用。
- 点击“新的存放文件夹”弹出系统文件夹选择窗口，选择后显示路径，再次点击可更换，取消不清空原选择。
- 保存新位置后，下次启动先迁移并校验索引，再使用新位置扫描；本次运行继续使用原位置，重启前可取消切换。
- 迁移保留监控文件夹、隐藏规则、设置和内容索引，包含尚在 WAL 中的数据。
- 拒绝覆盖已有索引，拒绝将资料文件夹作为索引目录；目标不可用、身份变化或迁移失败时继续使用原位置并显示原因。
- 迁移后提供“定位旧索引”及清理说明。

## 使用方法

1. 打开左下角“索引存储”。
2. 点击“新的存放文件夹”，在其他磁盘选择一个专用空文件夹。
3. 点击“保存，下次启动生效”，退出并重新打开 FileM。
4. 再打开“索引存储”确认当前位置已切换，并检查已有文件和搜索结果。

## 空间与升级说明

旧索引副本会保留，迁移不会自动释放旧磁盘空间。确认新位置正常后，退出应用，再清理旧位置的 `index.sqlite`、`index.sqlite-wal` 和 `index.sqlite-shm`。不要删除整个应用数据目录，其中的小型 `storage.sqlite` 保存索引位置配置。

索引目录不参与扫描，请勿将资料目录或整个磁盘作为存放位置。当前索引所在磁盘不可用或文件丢失时，应用会报错，不会静默创建空白文件库。请接回磁盘或恢复文件后启动。

修改索引位置后，请使用 0.1.12 或更新版本；旧版不识别位置配置。索引数据库格式仍为版本 5。此版本没有新增磁盘空间配额或低空间自动暂停机制。

Windows 安装包未做代码签名；Windows 桌面的安装、原生弹窗、移动磁盘和长时间运行仍需实机验收。
