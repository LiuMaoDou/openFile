# FileM 首个工作台视觉约定

参考图：`filem-concept.png`，由内置 ImageGen 生成，原始尺寸 1536 × 1024。

主界面：左侧范围/文件类型导航，中间工具栏和文件列表，右侧按需展开文件详情，底部扫描状态。白色主区，浅灰绿色侧栏，深青绿色主按钮与浅绿选中行，1 px 分隔线。界面不使用参考图片作为控件。

设计变量：主色 `#29675b`，侧栏 `#f5f7f6`，选中背景 `#e8f0ed`，文字 `#24343b`，次要文字 `#7a858d`，边线 `#e2e7e6`。中文无衬线字体，标题 26 px，按钮/导航 13–14 px，列表行 52 px；小窗口优先保留文件名与目录。

参考图中的示例文件数量、大小、日期由真实扫描结果替代；影音合并、RAW 分类、扫描状态、范围编辑、隐藏/恢复、文本预览弹窗为既定功能需要。小窗口以抽屉呈现导航或详情，避免挤压表格。首次启动显示选择范围的空状态，不自动索引真实用户目录。

控件文案以“全部文件”“按类型聚合，文件保留在原位置”“添加范围”“搜索文件名或路径”“刷新”“文件详情”“预览文本”“复制路径”为基础。真实操作不以装饰按钮占位。当前开发阶段仅显示已实现的能力。

实现中的有意调整：

- 布局保留三栏结构；1536 px 视口左栏 260 px，详情栏 320 px，为列表多留一列空间。
- 文案保留关键动作，文件数、日期、后缀和顺序均由真实索引与排序产生。
- 字体与行高比参考图更紧凑，列表 52 px，方便工作台同时浏览更多记录。
- 青绿色按钮、浅绿选中行和灰白底色沿用参考；类型图标降低饱和度，使用 Lucide 矢量图标。
- 主区使用 28 px 水平留白；增加分页条、真实文本预览区、范围设置和已实现的系统动作。
- 初始页面不预选文件；单击仅显示详情，勾选才加入批量选择，避免把查看详情误当成操作选择。
- 删除使用低饱和红色，独立于绿色的浏览/隐藏操作。确认窗口逐项呈现原路径和结果；默认焦点在关闭入口，只有明确点击“移入回收站”才执行。
