# FileM Windows 使用说明

此分发目标为 Windows 11 x64（Intel / AMD 64 位）。无需安装 Node.js、Rust、Visual Studio 或运行终端命令。

## 安装版

双击 `FileM_0.1.3_x64-setup.exe`，按中文向导安装。完成后从桌面或开始菜单启动 FileM。

安装在当前用户目录。若系统缺少 WebView2，安装器会引导安装该运行时；这一步需要联网。程序首次启动为空白文件库，点击“添加文件夹”选择自己的文件夹。

## 免安装版

将 `FileM-0.1.3-windows-x64-portable.zip` **完整解压**，双击里面的 `FileM.exe`。不要直接在压缩包预览中启动。

此版本使用系统的 WebView2。若电脑缺少该运行时，请使用安装版。免安装指不需要安装 FileM；索引和操作记录仍保存在用户应用数据目录，不随 EXE 一起移动。

## 从 0.1.0 / 0.1.1 / 0.1.2 升级

先退出旧版 FileM，再安装或解压运行 0.1.3。已添加的 D 盘和其他文件夹会继续保留，并自动按正常路径显示，无需移除文件夹或清空索引。

索引会升级到版本 3 以保存移动记录；升级后请继续使用 0.1.3 或更新版本。

## 基本操作

- 添加一个盘或文件夹，按后缀查看不同目录里的同类文件。索引和筛选不移动源文件。
- 列表上方显示扫描状态和完成时间，左侧文件夹显示各自状态与数量。切换文件夹后，类型和后缀统计跟随变化。
- 单击文件名查看详情；勾选复选框加入批量选择，支持 Shift 连选和本页全选。
- 删除：勾选文件 → “删除文件” → 核对原路径 → “移入回收站”。文件变化或系统不能回收时会跳过/报错。
- 每行“类型”右侧有“系统打开”和“定位文件”按钮；双击文件行也可系统打开。
- 批量删除期间暂停扫描，结束或停止后自动继续。失败项会保留并显示具体原因，可处理原因后重新选择删除。
- 内置 1,377 条文件后缀图标映射，可离线显示；未知后缀显示扩展名标识。
- 移动：勾选文件 → “移动到…” → 选择目标文件夹 → 核对清单 → “确认移动”；同名文件跳过，不覆盖。
- Everything：安装并运行 Everything 1.4，勾选列表上方“Everything 加速”。SDK 已内置；未连接或查询超时时自动回退本地索引。仍只在添加的文件夹内搜索。
- “从视图隐藏”只影响列表，不删除源文件。
- “删除记录”保留每项结果。恢复文件请在 Windows 回收站操作；FileM 不自动重试中断操作或永久删除失败项。

## 当前版本状态

这是 0.1.3 开发验证版。修复和验证结果见同目录的修复记录；macOS 上的界面及回收测试不能替代 Windows 实机功能验收。该 Windows 包未做代码签名。

首次试用请使用自己新建的测试目录，核对添加文件夹、文本预览、系统打开、批量回收和系统回收站恢复。无需关闭 Windows 安全功能；若系统或单位策略阻止未签名软件运行，应按相应策略处理。

安装包中嵌入了运行时安装引导程序，具体机制见 [Tauri 官方说明](https://v2.tauri.app/distribute/windows-installer/#embedded-bootstrapper)。
