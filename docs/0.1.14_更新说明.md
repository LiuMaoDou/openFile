# FileM 0.1.14：查询性能与交互稳定性优化

本次仅发布 Windows x64 便携 ZIP 和 SHA-256 校验文件。

## 查询与索引

- 合并文件总数、隐藏数和容量统计，减少重复扫描。
- 分页内复用文件夹信息及摘要查询，减少逐行重复 SQL。
- 关键词正文搜索先使用现有 trigram 索引缩小字面匹配候选，保留短词、中文、标点及技术符号的匹配行为。
- 只修改正文索引提示、容量等元数据时，不再重建整篇全文索引。
- 修改文件夹监听设置时保留已有正文；修改范围规则时保护其他启用文件夹共享的正文。配置与索引失效在同一事务中更新，失败完整回滚。
- 移除扫描结束时重复清理和无效开关，继续在事务内清理失效记录。
- Everything 候选保留搜索词用于相关度排序，同时保留路径别名匹配。

## 界面与开发服务

- 修复 Shift 连选在状态批处理下可能只选中端点的问题。
- 切换文件或关闭详情后，忽略过期预览结果与错误；浏览器开发模式还会取消对应请求。
- 本地服务恢复后重新查询列表，并清除对应旧连接错误；用户操作的新错误继续保留。
- 复用日期格式器，减少列表渲染中的重复初始化。
- 开发启动检查服务身份，避免将占用同一端口的其他项目当作 FileM；支持设置 `FILEM_DEV_PORT`。

## 使用与升级

退出旧版，完整解压 `FileM-0.1.14-windows-x64-portable.zip`，双击 `FileM.exe`。原有文件夹、隐藏规则和索引位置继续保留。便携版使用系统 WebView2；缺少时请先安装 Microsoft WebView2 Evergreen Runtime。索引保存在用户应用数据目录或已设置的位置，不随 EXE 移动。

## 验证与边界

本地通过 116 项 Rust 测试、15 项界面单元测试、构建、Clippy 零警告和格式检查；真实解析验证覆盖 PDF、DOCX、XLSX、PPTX、大文本、32 MiB 边界、关键词搜索及有界预览。Chrome 验证覆盖连选、搜索、预览与断线恢复。

Windows 自动化检查结果见对应 GitHub Actions。交叉构建、自动化测试和包结构检查不能替代 Windows 桌面、移动磁盘及长期运行的实机验收。可执行文件未做代码签名。
