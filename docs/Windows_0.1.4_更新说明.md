# FileM 0.1.4：本地内容搜索

本版增加类似 AnyTXT 的文件正文搜索，使用内置解析器与本地 SQLite FTS5 索引。无需安装 AnyTXT、Everything、Java 或 Office，文档内容不会发送到外部服务。

## 使用方法

1. 添加需要搜索的文件夹，在设置中勾选 **启用内容索引**。已有文件夹也可以在列表上方的 **内容索引** 面板中开启。
2. 等待面板显示处理完成。可查看可搜索、待处理、失败、跳过和截断数量，并展开失败原因。
3. 将搜索模式改为 **文件内容**，输入关键词。**文件名 + 内容** 会合并两种命中并去重；**文件名 / 路径** 保持原有行为。
4. 结果显示高亮命中片段，点击文件可在详情中预览提取的文字。

可对每个文件夹独立暂停、继续、重建和关闭内容索引。暂停保留已提取内容；关闭清理没有其他已开启文件夹引用的索引文字。移动、修改或删除文件后，相关内容随文件索引一起更新或失效。

## 支持范围

- TXT、Markdown、常见代码和配置文件；UTF-8、带 BOM 的 UTF-16、GBK。
- 带文字层的 PDF、DOCX、XLSX、PPTX。预览是提取文字，保留原版式的文档查看仍使用系统打开。
- 中文单字、短词和中英文混合短语；连续字面量匹配，英文不区分大小写。空格不作为 AND 运算符，不提供正则、通配符或自然语言问答。
- 文件夹筛选、类型筛选、隐藏状态与文件列表操作继续适用。

## 首版限制与升级

- 单文件最大 64 MiB，最多索引 2 MiB UTF-8 文字；达到上限会标记截断。独立解析进程最多运行 30 秒，Windows 内存上限 512 MiB。
- 扫描版 PDF、图片 OCR、旧版 DOC/XLS/PPT、WPS 专有格式和压缩包内容暂不支持。特殊 PDF 字体、损坏或加密文件可能失败，请查看具体原因。
- 3 个及以上字符使用 FTS5 trigram 索引；1～2 个字符搜索已保存的文字，大量文档时会较慢。尚未验证百万文档性能。
- 升级会将索引数据库更新为版本 4。旧版应用不能直接打开升级后的数据库；文件夹的内容索引默认关闭，需要手动开启。
- 索引文字保存在本机应用数据目录，不加密。关闭索引会删除逻辑记录，不保证安全擦除数据库空闲页、WAL 或备份。
- 免安装版依赖系统 WebView2；安装版可在缺少时联网安装。Windows 用户桌面的目录选择、跨盘、网络盘和云占位文件仍需实机验收。

源码与每次提交的自动检查结果见 [openFile](https://github.com/LiuMaoDou/openFile) 和 [GitHub Actions](https://github.com/LiuMaoDou/openFile/actions)。
