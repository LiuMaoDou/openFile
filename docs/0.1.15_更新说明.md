# FileM 0.1.15 · 失效文件选择清理（Windows）

本版本基于 0.1.14 发布代码，不回退已有查询、内容检索或性能改进。

## 修复

- 删除或移动预览中明确标记无法在 SQLite 索引中找到的旧文件 ID，自动从前端已选文件集合中移除。
- 失效 ID 不再反复显示为「0 个可删除 / N 个将跳过」，同时保留其余有效文件的可操作性。
- 文件仍有索引但暂时不可访问时，继续标记不可操作，不错误地视为失效选择；不绕过已有身份、权限和回收站安全校验。
- 加入 Rust 回归测试，覆盖索引缺失、正常文件和路径暂不可用的区别。

## Windows 发行包

- Windows x64 安装版：`FileM_0.1.15_x64-setup.exe`。
- Windows x64 便携版：`FileM-0.1.15-windows-x64-portable.zip`。
- `SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。

Windows 和 macOS 的自动化检查通过后，GitHub Actions 在 Windows Runner 上编译并发布构建产物。便携版需要系统 WebView2；安装版由 Tauri 配置处理 WebView2 的安装。构建通过不等于完成 Windows 长期运行或多磁盘场景的实机验收；发行文件没有代码签名。
