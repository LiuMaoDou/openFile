# FileM 0.1.17 · 空格分隔多关键词搜索（Windows）

本版本基于 0.1.16，将已有的关键词匹配设为默认搜索方式，保留文件索引、内容搜索、列布局和文件操作功能。

## 搜索改进

- 打开应用即可输入 `xx yy` 搜索，要求 `xx` 和 `yy` **全部匹配（AND）**；仅包含其中一个词的文件不会命中。
- 关键词不要求连续或按输入顺序出现。例如 `xx_资料_yy.txt` 和 `yy_资料_xx.txt` 都可命中；首尾空白、连续多个空格以及重复关键词均可正常处理。
- 默认按 **相关度优先** 排序，也可切换为文件名、大小、修改时间等排序。搜索框提示明确说明用空格分隔关键词。
- **文件名 / 路径** 模式要求每个关键词出现在名称或路径中；**文件内容** 模式只搜索已开启内容索引并完成提取的正文；**文件名 + 内容** 模式要求名称/路径或正文一侧满足全部关键词。
- 仍可切换到 **精确匹配**，按连续原文查找包含空格或特殊符号的完整短语。关键词模式沿用中文分词和本地索引，单次最多 32 个词；精确文件名搜索仍可使用 Everything 加速。

## Windows 发行包

- Windows x64 安装版：`FileM_0.1.17_x64-setup.exe`。
- Windows x64 便携版：`FileM-0.1.17-windows-x64-portable.zip`。
- `SHA256SUMS.txt`：安装版与便携版的 SHA-256 校验值。

下载与校验值见 [v0.1.17 Release](https://github.com/LiuMaoDou/openFile/releases/tag/v0.1.17)。便携版完整解压后运行 `FileM.exe`，依赖系统 [Microsoft WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；安装版由 Tauri 安装流程处理 WebView2。使用者无需安装 Node.js、Rust 或 Visual Studio。

安装包尚无代码签名；Windows 实机交互与多磁盘场景仍需验证。自动检查结果以对应的 GitHub Actions 记录为准，CI 编译与测试通过不等于所有实际设备均已验收。本次仅发布 Windows x64 安装版与便携版。
