# FileM 0.1.9：扫描进度与异常可观测性

本版在 0.1.8 的扫描并行基础上，补齐扫描可观测性：先统计目录树后再计算比例、显示单次核对范围与原因、增加版本显示，并对异常停滞给出提示。

## 版本信息

- 显示安装包版本号（左下角），帮助确认当前运行的构建。
- 发布版本号统一为 0.1.9。

## 扫描与进度

- 全局扫描先做目录计数：全局进度以“已处理目录 / 预计目录”为基准，不再因扫描中期才发现总量而跳变。
- 每轮全局扫描按目录粒度显示“已统计 / 已处理”，每次目录统计和实际提交都有明确阶段。
- 目录变化过多、监听事件丢失或手动刷新导致的完整核对，会在扫描记录中保留触发原因，便于判断为何重复扫描。
- 当扫描停滞超过 60 秒无新增进度时，会显示停顿告警，提醒优先确认路径权限、网络/云目录或扫描是否被系统 I/O 阻塞。

## 使用建议

- 目录过大时建议先配置排除规则再启动；优先覆盖常用资料目录。
- Windows 下可配合“从头开始监听”与“文件夹变化溢出”提示判断是否需要清理过期状态或暂停监听。

## 验证与边界

本地新增了进度展示和扫描原因的 UI/逻辑单元测试，并保留 68 项核心/集成测试覆盖与扫描流程。

仍未提供完整“重复扫描收益”基准结果；性能影响以实际用户环境的目录结构和网络盘为准。签名状态与 0.1.8 保持一致：暂未进行官方代码签名和公证。
